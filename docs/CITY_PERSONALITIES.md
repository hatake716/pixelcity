# 都市の個性と街の暮らし（0.4.2）

フェルトの毛羽・布の凹凸・丸い縁・縫い目を残し、染めた布の色を鮮やかにした。
色指定をsRGBからBlenderの線形RGBへ変換し、白い光沢を弱めた。
都市の様式を切り替えると、専用の建築・樹木・地面・水面・歩道が切り替わる。

| 様式 | 建築と配色 |
| --- | --- |
| 大都市 | 青と白、桃色の縦飾り。高層建築、段状の屋上、屋上設備 |
| 田園 | 黄色と若草色の低層住宅、赤い切妻屋根、花壇と深緑の木々 |
| 工業 | 煉瓦色と山吹色、濃灰色の屋根。配管、貯槽、倉庫設備 |
| 古代 | 黄土色と砂色の低層建築、胸壁、青緑色の丸屋根 |
| 未来 | 薄紫と薄荷色、丸い天蓋、張り出した屋根 |
| 欧州 | 珊瑚色と黄金色の壁、屋根窓、縞模様の庇、窓辺の植栽 |
| 和風 | 生成りと藍色、深い軒、木の縦桟、朱色の飾り、桜色の樹木 |
| 標準・独自配色 | 標準は六色の建築。独自配色は既存の分類別色編集を継続 |

大都市・田園都市・工業都市のシナリオは従来どおり対応する様式を使用する。
完成都市の大都市見本に標準様式が設定されていた点を修正し、港町の見本・タイトル背景は欧州様式にした。
既存の保存済み都市は、保存していた様式で表示する。
様式を変えても建築の発展段階、人口、収支、シナリオの条件は変化しない。

## 車と歩行者

車が横向きに走っていた原因は、画像生成用カメラとゲーム内のX/Y軸の対応の不一致。
画像生成時の回転を補正し、乗用車・バン・トラック・バスの全7車種、各4方向を再生成した。
東は画面右下、南は左下、西は左上、北は右上へ車体の先端が向く。
回転前にBlenderの変換行列も更新する。

歩行者は服装6種、向き4方向、歩幅2姿勢の48画像。
帽子・鞄、服・肌・髪の色に違いを付け、腕と脚を交互に動かす。
建築や公園に隣接する、接続した生活道路・大通りの歩道を往復して散歩する。
高速道路、水上、未接続道路には配置しない。道路撤去は即座に表示へ反映する。
大通りには幅に合わせて外側の歩道を使い、交差点には横断歩道を描く。

歩行者は街の装飾アニメーションであり、住民ごとの通勤経路・人口計算ではない。
同じ道路の人は画面移動で位置が変わらないよう固定の種を使う。
時刻は倍精度で扱い、長時間起動後も歩行が小刻みに飛ばないようにした。
描画は見えている範囲で最大240人、遠景では省略する。車・建物と同じ奥行き順で描く。

## 素材と再生成

基本113画像 + 都市様式専用161画像 + 歩行者48画像 = 322画像。
各様式の専用素材は、住宅・商業・工業 × 3段階 × 2画像と、公園・林・農場・給水塔・学校。
草地・海の染色は繊維の明暗を保持し、道路の布・砂浜・縫い目も継続する。
都市様式を変更すると地面キャッシュを更新し、建築キャッシュは88MiB以内に制限する。

色の原本は `visual-source/city-themes.json`。BlenderとAndroidで共用する。
全て独自制作のフェルト素材・人形・建築。MIT。記念建築の形の参考写真については既存のCC0出典台帳を継続する。

```sh
nix shell nixpkgs#blender --command blender -b -t 12 -P tools/realistic/build_assets.py -- --felt
nix shell nixpkgs#blender --command blender -b -t 4 -P tools/realistic/felt_ground.py
python3 tools/realistic/package_assets.py --felt
python3 tools/realistic/verify_assets.py --felt
```

生成済みの画像はgenerationを確認して再利用する。生成コードを変更して同じIDを作り直す場合は、
対象の `artifacts/felt/rendered/<ID>.json` を削除するかgenerationを更新する。
アプリにはWebPとパレットのみを収録し、制作資料・元写真・編集用GLBは含めない。

表示確認と実機更新の証跡は [検証記録](CITY_LIFE_VALIDATION.md) を参照。
