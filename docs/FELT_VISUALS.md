# フェルトの街と漢字表記（0.4.1）

この文書は0.4.1時点の変更記録。現在の素材数・配色・車と歩行者・再生成方法は
[都市の個性と街の暮らし（0.4.2）](CITY_PERSONALITIES.md)を参照。

クオータービューの2:1タイル、既存の都市形状、カメラと建設・保存の仕組みを保ち、
画面内の建築・土地・海・車・樹木を布細工の質感へ変更した。

## 街の素材

- 建築54種、公共施設・緑地など22種、記念建築8種、車7車種×4方向、ヨット1種、合計113画像を再生成。
- 独自の繊維模様と凹凸でフェルトの毛羽を表現。金属やガラスも艶を抑えた布の部品へ置換。
- 壁や窓の縁を丸くし、屋根の縁や窓に短い縫い目を追加。赤・生成り・淡青・緑・薄桃の配色。
- 樹木は綿を詰めた丸い房、幹は布を巻いた形。旧版の実写植物モデルは使わない。
- 草地、砂浜、道路、海の4素材も同じフェルト材質で生成。土地の縁にステッチを追加。
- 海は青いフェルトの上に波形の布を重ね、糸で縫った表現。鏡面反射のある旧水面を置換。
- タイトル・メニュー・本編UIの色を、濃茶・生成り・淡い黄土色へ調整。

3D形状を正投影でレンダリングし、高解像度WebPをAndroid Canvasに描く方式。
前版で修正したピンチの連続倍率と中心固定を引き継ぐ。
モニュメントの形状は引き続き実際のCC0写真を参照した独自制作であり、写真測量スキャンではない。

## 項目名・案内

地図の凡例、推移グラフ、条例、配色、災害頻度、予算、建築名・説明、調査結果、
保存・削除確認、通知、保存日時、模範都市の名称を自然な漢字表記に統一。
例えば「じゅうたく みつど」→「住宅密度」、「がいせんもん」→「凱旋門」、
「しょうエネ じょうれい」→「省エネ条例」、「つづきから」→「都市再開」。
タイトルの新規プレイは「新規開始」、自由モードは「自由建設」。

チュートリアル本文内の旧ボタン名も「実行」「取消」「調査」「都市情報」「予算」に統一。
固有名「ひより」、助詞・送り仮名、会話の自然な言葉遣いは保持する。
列挙型のID・保存形式・ゲームの計算式は変えていない。

## 出典と再生成

フェルトの繊維・布・糸・樹木は独自制作、MITライセンス。
現行の描画に外部写真テクスチャや外部植物モデルは使用しない。
`visual-source/felt-sources.json`に生成コード、繊維の乱数シード716、画像のハッシュを記録する。
記念建築の参考写真と旧版の写真素材は`visual-source/sources.json`に記録を残す。
アプリ内のクレジットでも現在使用する素材と旧版の制作資料を区別して説明する。

```sh
nix shell nixpkgs#blender --command blender -b -t 8 -P tools/realistic/build_assets.py -- --felt
nix shell nixpkgs#blender --command blender -b -t 4 -P tools/realistic/felt_ground.py
python3 tools/realistic/package_assets.py --felt
python3 tools/realistic/verify_assets.py --felt
```

Blender 5.1.1 / Cycles、ffmpeg WebPで作成。
作業用PNGは`artifacts/felt/`、記念建築の形状データは`visual-source/felt-models/`。
ゲームの素材パスは互換性のため`assets/realistic/`を維持するが、全113件の`finish`は`felt`。
素材を再調整した場合は対象の作業用PNG・JSONを消して再生成する。
旧写真版は`--felt`を外して再生成できる。梱包時は仕上げの混在を検査し、方式切替時は全画像を更新する。
