# 写真素材と3Dによる街並み刷新（0.4.0）

クオータービューの2:1タイルと既存の都市・チュートリアル・シナリオを保ち、都市の描画を刷新した。
ゲーム画面はAndroid Canvasへ高解像度のRGBA画像を直接描き、カメラ位置と倍率を浮動小数点で扱う。
従来のパレット縮小画像を拡大する経路は本編・タイトル・お手本一覧で使用しない。

## 建築と素材

`tools/realistic/build_assets.py`でBlenderの3Dメッシュを組み立て、Cyclesで正投影レンダリングする。
カメラ仰角30度、方位45度。地面1タイル幅512pxを基準に画像と接地アンカーを出力する。

- 住宅・商業・工業：3成長段階×6形態＝54種類。屋根窓、窓枠、バルコニー、日よけ、屋上の緑などを立体化。
- 公共施設・インフラ・公園・樹林：22種類。
- 実在の記念建築：8種類。東京タワー、凱旋門、コロッセオ、自由の女神、ビッグベン、ピサの斜塔、タージ・マハル、ピラミッド。
- ヨット：1種類。水面も波の凹凸と光の反射をBlenderで描画。
- 車：7車種×4方向＝28画像。交通量と進行方向は既存の交通シミュレーションに連動。
- 草地、砂、アスファルト、石、瓦、レンガ、漆喰：Poly Havenの実写PBRテクスチャ。
- 街路樹と低木：Poly HavenのTree Small 02 / Shrub 02のCC0モデルを縮小・回転して組み込み。ゲーム用画像に必要な密度へ樹木を簡略化。

記念建築は、CommonsでCC0を確認した実際の写真から外形・構成・色を読み取り、独自にメッシュを制作した。
**写真測量やフォトグラメトリによるスキャンではない。** 写真に写らない面、正確な寸法、細かな彫刻は推定・簡略化している。
写真そのものを模型へ自動変換したと説明しない。
`visual-source/models/*.glb`は編集可能な3Dデータで、メッシュ・UV・材質・写真URL・作者・写真ハッシュを含む。
ゲーム内には軽量なレンダリング画像を収録し、3Dソースや元写真はAPKへ入れない。

画像は見下ろし方向を固定した3D由来の表現で、端末内で自由回転する3Dエンジンではない。
ガラスや陰影はレンダリング時の照明を焼き込んでいる。昼夜に応じて反射や影を物理的に再計算する方式ではない。

## 操作・UI

- ピンチは2指の重心と距離を使い、拡大・縮小と平行移動を一度の座標変換で処理する。旧1/256丸め、入力の0.4%閾値、片方の指による余分なパンを廃止。
- 描画・タイル選択・ピンチ固定点で同一の投影式を使用。屋根の調査には表示画像の透明度を使う。
- 指が増減した時は基準点を取り直し、キャンセル時は建設候補を復元する。倍率の上限・下限とマップ端ではカメラを制限する。
- タイトルはOutfitの太いロゴ、動く街と車、グラデーション、大きなネイティブ操作カード。背景更新は32ms間隔で予約し、メインスレッドの操作処理に時間を残す。
- タイトル・保存先・お手本選択はネイティブ文字とScrollView。日本語の説明、リップル、フォーカス、読み上げ用ラベルを付けた。削除は明示的なボタンから既存の確認画面へ進む。
- 本編の主要操作は64論理px以上、分類64px、建設道具88px。1080px / 420dpiの検証端末では約49dp以上の高さ。別サイズの端末での操作感は別途確認が必要。
- 都市情報は3列×2段のタブ。条例・地図・設定・グラフは大きな行と縦スクロールにし、最後の項目まで選べる。
- 従来の部分別パレット編集は、新しい写真素材の陰影を維持する住宅・商業・工業・公共施設の色調編集へ移行。以前の17項目はセーブ内に保持する。現在の描画では4種類の壁色項目を色調として使用する。
- 秘書ひよりの肖像、物語、3シナリオ、BGM・SE、都市の数値と保存形式は継続する。

## 出典・再生成

出典・作者・ライセンス・改変内容・SHA-256：`visual-source/sources.json`。
CommonsのAPIメタデータ：`visual-source/references/*.metadata.json`。
Outfit：Google Fontsから改変せず収録、SIL OFL 1.1。本文はAndroid標準サンセリフ。
アプリの「クレジット・ライセンス」でも出典とライセンスを読める。

```sh
python3 tools/realistic/fetch_sources.py
python3 tools/realistic/fetch_vegetation.py
nix shell nixpkgs#blender --command blender -b -t 8 -P tools/realistic/build_assets.py
nix shell nixpkgs#blender --command blender -b -t 8 -P tools/realistic/water_surface.py
python3 tools/realistic/package_assets.py
python3 tools/realistic/verify_assets.py
```

Blender 5.1.1、Cycles CPU、24サンプル・デノイズ、AgXで検証。画像変換にはffmpeg/libwebpを使用。
レンダリング済みPNGとJSONがあるモデルはスキップする。形状や材質を変更した場合は、対象の`artifacts/realistic/rendered/<ID>.png`と`.json`を削除して再生成する。
元写真と高密度植物モデルのダウンロードには時間とディスク容量が必要だが、実行時のネットワーク接続は不要。
