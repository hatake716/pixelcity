# マスの選択色と、ひよりの表示切替（0.6.5）

2026-09-13。`io.github.hatake716.pixelcity`、versionCode 20。

## 操作と描画

- 球体上で選択したマスの塗りを濃い青（基準色 `#14337A`）、枠を `#12306E` に変更。実際の表示には地面の素材色と照明が合成される。
- 地形編集の選択位置・筆の枠、平面描画の選択と記念建築の配置予定枠も青で統一。
- チュートリアルの推奨場所は金色のまま。そこを実際に選択すると青が優先され、推奨と選択を区別できる。
- ひよりの案内がある間、上部の「座標指定」の右隣に「ひより」を表示。同じボタンで開閉し、表示中は強調色にする。
- 非表示にすると、チュートリアルの顔・文章・目標・返答ボタン、またはシナリオの案内欄が消える。その場所の見えないタップ判定もなくなり、建設メニューの状態に応じて地図の移動／マス選択に使える。
- 表示切替そのものは物語を進めず、資金・都市・建設予定の選択・カメラを変更しない。目標達成や返答の条件は継続する。
- 非表示中にシナリオの新しい助言が届いても市政手帳を自動で開かず、ボタン右上に未読印を残す。「市政」→「市政手帳」は明示的な操作として利用できる。
- 縦画面・横画面・建設トレイ表示中に対応し、カメラ穴の余白を保つ。画面回転では同じ開閉状態を維持する。
- 開閉状態はそのプレイ画面内の表示設定。都市を開き直すと表示から開始する。都市の保存形式は変更しない。
