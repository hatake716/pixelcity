# 建設メニューの開閉と横画面（0.6.4）

2026-09-13。`io.github.hatake716.pixelcity`、versionCode 19。

## 操作

新規開始、模範都市、保存した都市の再開は、建設メニューを閉じた状態から始まる。
上部バーの「調査」の右隣に「建設」を置き、同じボタンで開閉する。開いている間は強調色で表示する。

| 状態 | 一本指 | 二本指 |
|---|---|---|
| 建設メニュー非表示 | ドラッグで地球・地図を移動 | ピンチで拡大縮小、ドラッグで移動 |
| 建設メニュー表示 | タップ／なぞりでマス選択。選択済みマスは再度押すと解除 | ピンチで拡大縮小、ドラッグで移動 |
| 調査を選択 | 建築や土地をタップして情報を表示 | ピンチで拡大縮小、ドラッグで移動 |

一本指で触れただけでは建設費は発生しない。選択後の「実行」で建設する。
二本目の指が加わると、そのジェスチャーの一本目で変化した選択を元に戻す。
指を一本に戻しても、全ての指を離すまで建設選択を再開しない。
ピンチ開始時に実際の地形メッシュとの交点を一度取得し、標高を含む同じ地点が指の中心に留まるようカメラを補正する。移動中の毎フレームに地形全体との交差判定を繰り返すことはない。
建設メニューを閉じると、未実行の選択と記念建築の配置待ちを取り消す。資金・設置済み建築は変わらない。

「市政」から都市情報、予算、地形編集、記念建築、市政手帳へ移動できる。
チュートリアル中は学習段階に応じた制限を維持する。記念建築を選ぶと建設メニューが開く。
「地形編集」は建設メニューを閉じて開く。無料編集、BGM継続、都市時間停止を維持する。

## 横画面

- 端末の回転設定に従って縦・横・逆横に対応。同じActivity、City、PlanetSurfaceを保持し、表示だけを組み替える。
- 縦：上部ステータス＋操作バー、下部の建設トレイ。非表示では地図が下端まで広がる。
- 横：人口・資金と操作を一段のバーへまとめる。建設メニューは右側へ表示し、地図の高さを保つ。閉じると地図が横へ広がる。
- 施設一覧は三列。上部の分類ボタンで切り替え、上下スクロールで施設を選ぶ。費用と実行・取消は一覧下部へ固定する。
- タイトルは左にロゴ、右に開始メニュー。どちらも必要に応じてスクロールできる。
- 横画面のひよりは短い目標帯と相談ボタン。説明・返答・公園／診療所の選択は全文を読めるダイアログで扱う。
- 市政手帳の都市選択は三列、政策は本文と選択肢を左右配置。横画面で政策を押すと費用・月額・説明の確認画面を開き、実施ボタンで決定する。
- 予算・記念建築・調査結果の長い本文はスクロール可能。見出しと閉じるボタンを固定する。都市情報のタブは広い画面で六列にする。
- カメラ穴とシステムバーの上下左右の余白を再取得し、描画とタップ判定に同じオフセットを使う。

都市の保存形式は変更しない。メニューの開閉は一時的な画面状態であり、セーブデータへ書き込まない。
