# ひよりと進める三つの都市シナリオ

0.3.0で追加。チュートリアルの最後の返答から、ひよりが三つの都市計画を提案する。
選んだルートはその保存枠の街で進める。地形、建物、資金、年月を引き継ぐ。
別のルートは別の保存枠で新しく始められる。選択前は「あとで選ぶ」で街へ戻れる。

各ルートは5章、各章に2つの政策案。合計15章・30政策案。
人口や建物を自動生成して完成させるのではなく、プレイヤーの実際の都市の状態を調べる。
選んだルートに合わせて初期の街並みの配色を大都市・田園・工業へ変更する。

## 大都市 ― 多文化共生の大都市

| 章 | 課題 | 選択肢 | 人口の節目 |
|---|---|---|---:|
| 届き始めた苦情 | 生活ルール・騒音と行政へのアクセス | 市民相談窓口 / 地区の相談員 | 1,000 |
| 安心して帰れる通り | 窃盗への対応と若者の孤立 | 街灯と地域巡回 / 就労支援と見守り | 5,000 |
| いくつもの言葉で暮らす | 海外からの家族と既存住民の行き違い | 多言語の生活センター / 学校通訳と交流教室 | 12,000 |
| 住まいを失わない成長 | 住宅不足・家賃・通勤負担 | 家賃相談と住宅支援 / 交通沿線の生活支援 | 20,000 |
| 三万人の市民と決算 | 公平なサービスと住民参加 | 公開予算と市民監査 / 地区ごとの参加型予算 | 30,000 |

出身・国籍を犯罪率へ結びつける計算は行わない。多文化共生は通訳・相談・教育・生活サービスへのアクセスで育つ。
犯罪指標は既存の密度・失業・地価・警察・教育の計算に、選択した防犯施策を反映する。
苦情は住宅サービスの不足、公害、犯罪指標、失業、渋滞、税率から求める。

完成には人口30,000人、高層住宅300・高層商業100、警察8・学校10・病院4・バス停12が必要。
共生70以上、住民信頼65以上、苦情30以下、住宅地の犯罪指標25以下、渋滞40%以下を保つ。

## 田園都市 ― 自然と生きる田園都市

| 章 | 課題 | 選択肢 | 人口の節目 |
|---|---|---|---:|
| 残したい風景 | 緑の保全と住まい・仕事 | 里山と農地の保全協定 / 市民の森と共同菜園 | 1,000 |
| きれいな電気の値段 | 発電転換と維持費 | 省エネ改修の支援 / 地域電力の共同運営 | 2,000 |
| 嵐が来る前に | 消防・避難・耐風対策 | 避難所と耐風改修 / 防災林と地域の備蓄 | 3,000 |
| 自然を守る仕事 | 環境対策を支える地域経済 | 地産地消の取引支援 / 環境学習と農業体験 | 4,000 |
| 次の世代へ渡す田園 | 保全と訓練を続ける体制 | 自然保全の市民基金 / 流域の防災協定 | 5,000 |

完成には人口5,000人、農地80・公園80、整備した緑地率30%以上、再生可能電力100%、消防署3が必要。
住宅地の公害10以下、防災力70以上、環境施策への信頼70以上を保つ。
緑地率の分母は開発済みの建築敷地。広い未開発地で数字を薄めることはできない。

このルートの天候リスクは開始6か月後から、サンドボックスの災害設定にかかわらず継続する。
第3章の説明でも明示する。竜巻・暴風雨・落雷による火災が、実際の建物の成長段階を下げ、応急費を発生させる。
防災力は政策の備えと、稼働する消防署から8マス以内にある住宅の割合で求める。
月の発生確率は防災力に応じて14%から4%へ下がり、被災区画数・成長段階の損失・応急費も減る。
十分な備えがあっても、天候リスクがゼロになることはない。

## 工業都市 ― 住民と歩む産業都市

| 章 | 課題 | 選択肢 | 人口 / 工業雇用の節目 |
|---|---|---|---:|
| 大企業からの提案 | 企業誘致と公共負担の協定 | 基幹企業との雇用協定 / 複数企業の連携団地 | 1,500 / 800 |
| 止められない生産ライン | 工業団地の水・電気・物流 | 共同物流と職業訓練 / 安定供給の設備協定 | 3,500 / 2,000 |
| 煙の向こうの暮らし | 公害への抗議と排水・排出対策 | 排出規制と共同改修 / 第三者測定と設備更新 | 6,000 / 4,000 |
| 工場ゲートの向こう側 | 設備損壊への対応と対話の再建 | 公平な捜査と公開協議 / 第三者仲裁と地域見守り | 9,000 / 6,000 |
| 産業と暮らしの共同協定 | 雇用・環境・地域還元 | 雇用と環境の三者協定 / 地域還元と技術転換 | 12,000 / 8,000 |

『暁モビリティ』『川の会』はこの物語の架空の企業・団体。
第4章では反対派の一部による測定装置の損壊（修繕費350）が起きる。
平和的な抗議と違法行為を分け、行為に応じた捜査と、公害の改善・対話を両立させる内容。
住民信頼が35未満のまま続くと、開始6か月後から半年ごとに追加の設備損壊・修繕費が発生する。

完成には人口12,000人、工業雇用8,000人以上かつ全雇用の60%以上、高成長工場100、大通り24、
下水処理場1、公園40、病院3が必要。工場の道路・電気・水道充足95%以上、住宅地の公害15以下、
犯罪指標25以下、住民・環境団体の信頼70以上、企業信頼65以上を保つ。

協定を結ぶと、企業の工業雇用需要が章と人口に応じて増える。
協定収入は工業雇用800人以上、工場のサービス充足95%以上、電力・水の供給余力を満たすときだけ発生する。
空き区画を置いただけで企業の需要を満たした扱いにはしない。

## 共通の経営と完成条件

- 政策には一度限りの導入費と、固定費＋人口に比例する毎月の費用がある。選択画面に金額を表示。
- 資金が足りなければ政策を採用せず街へ戻り、収入を増やせる。費用を踏み倒した進行はできない。
- 防犯・公害対策・住宅支援・企業需要は、既存の都市計算へ直接反映する。
- 住民信頼・多文化共生・企業信頼は、政策と実際の生活条件に応じて毎月変化する。
- 施設の条件は道路接続・通電を確認。道路自体は通電を要求しない。住宅地の公害・犯罪は入居済み住宅で平均する。
- 最終章では全ルート共通で、住宅サービス95%以上、失業15%以下、未処理ゴミ0、ゴミ処理能力の充足、資金0以上も必要。
- **全完成条件を保ち、6か月連続で収入が支出を上回る**と都市完成。赤字・サービス欠落などで連続記録をリセット。
- 応急費・修繕費も当月の支出に含める。予算見込みの閲覧や同じ月の再通知では連続記録を増やさない。
- 完成報告には都市の称号、年月、人口を記録。その都市をそのまま経営でき、政策の費用・効果と気象リスクも継続する。
- 「完成した街を経営する」を選ぶと、開発した範囲へカメラを合わせて街を見渡せる。
- 完成後に街が変化しても、達成当時の記録は残す。

## 市政手帳と保存

シナリオ中の街には小さな進捗帯を表示する。「市政手帳」で、ひよりの物語・目標と指標・採用した政策を確認。
長いページには「前へ」「次へ」を設ける。本文へのタップで政策を選択しない。
手帳を開いている間は時間を止め、閉じたときに読んだ時間をまとめて進めない。

都市セーブはv5。ルート固定ID、章、選択した政策、信頼、連続黒字、完成時の記録、最近の事件・気象報告を保存する。
旧v1〜v4も読み込み可能。旧版でチュートリアルを終えた都市には、街を保持して三つの提案を表示する。
自由開始・お手本の街には、勝手にシナリオを開始しない。保存枠の一覧にもルート・進行章・完成を表示する。

## 検証方法

`CampaignTest` では各ルートの全章を、政策をすべて第一案にする場合・すべて第二案にする場合の両方で完走する。
ここで使用する街は完成規模の建物・資金を配置した**検証用都市**。配置後は通常の月次計算を使い、
全条件・半年間の黒字・保存復元・完成後12か月の人口と財政を確認する。
この月数は、チュートリアルの小さな街から建設するのに要するプレイ時間ではない。

政策費の重複請求、資金不足、人口の数字だけでの誤達成、無接続施設、赤字と断水による記録のリセット、
防災による実被害の軽減、企業収入の条件、保存破損・旧版読み込みも検証する。

`StoryFlowTest` は「はじめから」から就任日誌を実操作で完走し、その直後に三つの提案が開くことを確認。
`CampaignFlowTest` は三つのルートの選択、政策採用、費用表示、ページ操作、保存と再開、
完成済みの検証用都市の読込・各ルートの結末・そのまま経営を続けられることをAndroid上で確認する。

完成都市のUI検証用JSONは `app/src/androidTest/assets/scenario/`。
`CampaignTest` に `-Ppixelcity.preview=<出力ディレクトリ>` を渡して書き出したもので、本体APKには同梱しない。

APK・実画面・最終チェックの結果は [SCENARIO_VALIDATION.md](SCENARIO_VALIDATION.md) を参照。
