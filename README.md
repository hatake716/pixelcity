# PIXELCITY

レトロ携帯機風のドット絵で遊ぶ、**都市経営シミュレーション**。
プレイヤーは市長として、財政を破綻させずに人口を最大化することを目指す。

## 遊びかた

1. 土地に**区分**（住宅 R・商業 C・工業 I）を指定する。区分は自動で発展する。
2. 区分が育つには **道路** と **電気** が要る。どちらが欠けても衰退する。
3. **税率**で収支を調整する。高すぎると人が出ていき、低すぎると資金が尽きる。
4. 公園・学校・病院・警察で**地価と住み心地**を上げると、より高い段階まで育つ。
5. 人口が増えると**世界の有名建築**が解禁される。観光収入と地価の大きな底上げになる。

資金がマイナスのまま12か月が過ぎるとゲームオーバー。

## チュートリアル

初めてでも迷わないよう、**1ステップにつき1つの操作**だけを案内する。
押すべきボタンは点滅し、関係のない操作はいったん受け付けない。

全11ステップを終えると、道路・発電所・住宅・商業・工業・公園がそろい、
**そのまま黒字で回り始める街**が手元に残る。タイトルから飛ばすこともできる。

## 技術的な話

- **論理解像度 160×144** に描いてから整数倍で拡大する。どの端末でもドットがにじまない。
- 色は **4階調のみ**。中間色を作らず、濃淡はディザ（市松模様）で表現する。
- ドット絵は 8×8 / 16×16 の**文字列としてコード内に**あり、外部の画像素材を持たない。
- シミュレーションは Android に依存しない純粋な Kotlin なので、単体テストで検証できる。

### ビルド

```bash
./gradlew :app:assembleDebug
```

`local.properties` に `sdk.dir` が要る。リリース署名は `keystore.properties`
（gitignore 済み）を置いたときだけ有効になる。

### テスト

```bash
./gradlew :app:testDebugUnitTest
```

シミュレーションの**バランス**もテストで守っている。街が成長すること、
振動しないこと、公共投資が報われること、チュートリアルを完走した街が
黒字で回ることを検証している。係数を触るときは必ず通すこと（[docs/BALANCE.md](docs/BALANCE.md)）。
